# POCAVERSE — Fandom Universe

포카버스(POCAVERSE) 기업 소개 홈페이지 1차 시안.

- 메뉴: 브랜드 · 판매기기 · 포토카드 · 굿즈 · 사업제휴 · 문의
- 다국어: 한국어 / English / 日本語 / 中文 (`?lang=ko|en|ja|zh`, 선택 언어 기억)
- PC · 태블릿 · 모바일 반응형
- 문의 양식: 입력 검증 + 접수 화면까지 동작 (서버 연동 전 시연용)

## 구조
```
index.html
assets/style.css   디자인
assets/app.js      메뉴·언어전환·포토카드 필터·문의폼
assets/i18n.js     EN/JA/ZH 번역 (KO는 HTML 본문)
assets/img/        사진
```

## 이미지
사진은 Unsplash 무료 라이선스 이미지입니다(상업적 사용 가능). 실제 판매기기·상품 사진이 준비되면 `assets/img/`의 같은 파일명으로 교체하면 됩니다.
